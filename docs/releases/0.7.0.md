# UsageBar 0.7.0

Claude와 Codex의 남은 한도·리셋 시각을 확인하는 macOS 메뉴바 앱입니다.

- 설정 → 앱 정보에서 새 버전을 확인하고 설치할 수 있습니다.
- 새 버전 자동 확인은 선택할 수 있으며, 설치와 재시작은 사용자가 결정합니다.
- 업데이트 후에도 설정·사용 기록·진행 중인 작업이 유지됩니다. 기록 저장 중에는 재시작을 잠시 미룹니다.
- 업데이트 파일과 변경 안내의 서명을 확인하며, 검증에 실패하면 기존 앱을 유지합니다.

macOS 14 이상·Apple Silicon을 지원합니다. 최초에는 ZIP을 풀어 UsageBar.app을 응용 프로그램 폴더에 넣고 실행하세요. 0.6.4 이하와 업데이트 경로가 없는 개발용 앱에서는 이번 배포본을 한 번 직접 설치해야 합니다.

사용량을 확인하려면 Claude Code 또는 Codex CLI의 기존 구독 계정 로그인이 필요합니다. UsageBar에 비밀번호나 API 키를 입력하지 않습니다.
