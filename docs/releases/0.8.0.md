# UsageBar 0.8.0

Claude와 Codex의 남은 한도·리셋 시각을 확인하는 macOS 메뉴바 앱입니다. 이번 버전은 화면 전체를 다시 다듬었습니다.

- 메뉴바 패널: 한 줄 헤더, 큰 잔여율 숫자와 세그먼트 게이지, 리셋 시각 한 줄. 패널 높이가 내용에 맞춰 줄어들고 Codex의 초기화권·일별 토큰이 스크롤 없이 보입니다.
- 작업 기록: 패널 아래 **작업 시작**에서 유형을 고르면 바로 시작합니다. 진행 중·완료 카드가 한두 줄로 줄었습니다.
- 첫 연결: 설치 → 터미널 로그인 → 돌아와서 확인의 3단계 안내. 한 서비스만 쓴다면 한 번에 다른 서비스 조회를 끌 수 있습니다.
- 사용 기록: 관측값 사이를 선으로 잇되 90분 넘게 빈 구간은 끊어 표시합니다. 설정·영수증 창도 같은 스타일로 정리했습니다.
- 영어 UI를 추가했습니다. 시스템 언어를 따르며, 한국어·영어가 아닌 환경에서는 영어로 표시됩니다.

macOS 14 이상·Apple Silicon을 지원합니다. 0.7.0에서는 설정 → 앱 정보 → 업데이트 확인으로 설치할 수 있고, 그 이전 버전은 ZIP을 풀어 UsageBar.app을 응용 프로그램 폴더에 넣어 주세요. 설정·사용 기록·진행 중인 작업은 유지됩니다.

---

**English** — 0.8.0 redesigns the whole interface: a one-line header, a segmented gauge for every limit, a panel that sizes to its content, a one-step work session start, and a numbered first-connection guide. The history chart now joins observations with a line, and the UI is available in English (follows your system language). Requires macOS 14 or later on Apple Silicon.
