# UsageBar 0.8.2

- **낮았던 한도가 리셋되면 알림.** 설정 → 알림에서 켜면, 20% 아래로 내려갔던 한도가 새 기간으로 리셋되어 돌아온 것을 실제 조회로 확인한 뒤 한 번 알립니다. 기존의 20% 이하 알림과 따로 켜고 끌 수 있습니다.
- 공개 저장소 정비: GitHub Actions CI(빌드·테스트)와 이슈 템플릿을 추가했습니다.

macOS 14 이상·Apple Silicon. 0.7.0 이상에서는 설정 → 앱 정보 → 업데이트 확인으로 설치할 수 있고, Homebrew는 `brew install --cask hyjoong/tap/usagebar`입니다.

---

**English** — 0.8.2 adds an optional notification for when a limit that had dropped below 20% resets and is available again, confirmed by a real check. The repository now runs CI on every push and has issue templates.
