# UsageBar 0.8.16

- **실수로 바로 끝나지 않게.** 패널의 "작업 시작"과 작업 중 "작업 종료"가 같은 자리에 있어서, 시작 직후 한 번 더 누르면 작업이 바로 끝났습니다. 이제 시작하고 5초 동안은 종료 버튼이 잠깁니다.
- **기록 중에는 더 자주 조회.** 작업을 기록하는 동안 그 서비스는 5분 대신 2분마다 조회합니다. 상태줄 숫자와 소진 예상이 작업을 더 빨리 따라옵니다. 다른 서비스와 평소 주기는 그대로 5분입니다.
- **상태줄에 방금 끝난 작업.** 작업을 끝내고 10분 동안 Claude Code 상태줄에 결과가 나옵니다. 예를 들면 `방금 작업 25분 · +3%p · Claude 92% · Codex 100%`입니다. 한도를 비교할 수 없으면 출력 토큰을 대신 보여 줍니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — 0.8.16 locks Finish for 5 seconds after a session starts, since Start and Finish share a spot and a second click ended the session at once. The service a session is recording is now checked every 2 minutes instead of 5, so the status line and run-out estimate keep up. For 10 minutes after a session ends, the Claude Code status line shows its result, such as `Last session 25 min · +3%p`, or the output tokens when the limit change could not be compared.
