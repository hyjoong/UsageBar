# UsageBar 0.8.14

- **Claude Code 상태줄.** 설정 → Claude Code 상태줄 → **상태줄에 표시**를 누르면 Claude Code 화면 아래에 이렇게 나옵니다.
  `● 기록 중 12분 · Claude 92% · Codex 100%`
  작업 기록 중이면 빨간 점이 붙습니다. 20% 이하면 주황색, 오래된 기록이면 흐리게 표시하고, 리셋 전에 바닥날 것 같으면 "오후 3:40 소진 예상"이 붙습니다. 터미널에서 일하는 동안 작업 기록을 켜 둔 걸 잊지 않게 해 줍니다.
- UsageBar는 이 버튼을 누를 때만 `~/.claude/settings.json`을 바꿉니다. 먼저 `settings.json.usagebar-backup`으로 백업하고 `statusLine` 항목만 추가합니다. 이미 다른 상태줄을 쓰고 있으면 바꾸지 않고, 기존 스크립트에 붙일 명령을 복사해 줍니다.
- UsageBar가 꺼져 있으면 10분 뒤 상태줄에서 사라집니다. **상태줄에서 빼기**로 언제든 되돌릴 수 있습니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — 0.8.14 adds a Claude Code status line. Settings → Claude Code Status Line → **Show in Status Line** puts a line like `● Recording 12m · Claude 92% · Codex 100%` at the bottom of Claude Code. It turns orange at 20% or less, dims stale readings, and adds "Runs out 3:40 PM" when a limit may run out before it resets. UsageBar changes `~/.claude/settings.json` only when you press that button. It backs the file up first, adds only the `statusLine` entry, and never replaces a status line you already have; in that case it copies a command to add to your script instead. The line disappears 10 minutes after UsageBar quits.
