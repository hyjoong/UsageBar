# UsageBar 0.8.7

영수증 카드를 다시 디자인했습니다.

- **헤드라인 숫자.** 5시간 한도 변화(`+6 %p`)를 크게 보여주고, 그 아래 게이지에 이 작업이 쓴 조각을 진하게 표시합니다.
- 리셋을 지나 한도를 비교할 수 없을 때는 빈칸 대신 출력 토큰과 호출 수가 헤드라인이 되고, 비교가 안 되는 이유를 한 줄로 적습니다.
- 영수증에 시작·종료 시점의 사용률을 함께 저장합니다. 이전 영수증은 그대로 읽힙니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew install --cask hyjoong/tap/usagebar`.

---

**English** — 0.8.7 redesigns the receipt card: the limit change leads as a big number with the session's slice highlighted on the gauge; when a reset makes the comparison impossible, output tokens and call count take the headline and the reason is shown.
