# UsageBar 0.9.0

이번 버전에서 새로 생긴 것:

- **최근 7일 요약.** 작업 영수증 창 맨 위에 지난 일주일이 합쳐져 나옵니다. 작업 횟수와 시간, 출력 토큰, 서비스별로 쓴 한도(%p), 작업 종류별 시간을 보여 줍니다. 리셋을 지난 추정값이 섞이면 "≈"를 붙이고, 비교할 수 없던 작업은 합계에서 빼고 몇 번이 빠졌는지 알려 줍니다. 버튼 하나로 텍스트로 복사할 수 있습니다.

0.8.10부터 쌓인 주요 변경:

- **메뉴 막대는 잔여율만.** U 아이콘 없이 숫자만 보이고, 20% 이하면 주황색이 됩니다.
- **소진 예상.** 최근 1시간 사용 속도로 5시간 한도가 리셋까지 버티는지, 몇 시에 바닥나는지 알려 줍니다. 리셋 전에 소진될 것 같으면 알림도 받을 수 있습니다.
- **Claude Code 상태줄.** 설정에서 버튼 하나로 Claude Code 화면 아래에 기록 중 표시, 서비스별 잔여율, 소진 예상, 방금 끝난 작업 결과를 띄웁니다. 기존 상태줄은 덮어쓰지 않습니다.
- **더 믿을 수 있는 영수증.** CLI가 업데이트되는 순간처럼 계정 정보를 잠깐 못 읽어도 기록이 지워지거나 영수증이 깨지지 않습니다. 시작 직후 5초간 종료 버튼이 잠기고, 기록 중인 서비스는 2분마다 조회합니다.
- **Codex 연결.** PATH 앞쪽의 오래된 Codex CLI 대신 실행 가능한 가장 높은 버전을 골라 씁니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — New in 0.9.0: the receipts window opens with a **last 7 days summary**: sessions, time, output tokens, the limit share each service used (estimates marked ≈, uncomparable sessions left out and counted), and time by session type, copyable as text. Since 0.8.10: the menu bar shows only the percentage and turns orange at 20% or less; a run-out estimate tells you whether the 5-hour limit lasts until the reset, with an optional alert; an optional Claude Code status line shows a recording session, each service's limit, the run-out time and the session you just finished; receipts survive a momentary account-metadata failure, Finish is locked for 5 seconds after Start, and the recording service is checked every 2 minutes; Codex discovery picks the newest runnable CLI.
