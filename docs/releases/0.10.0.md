# UsageBar 0.10.0

이번 버전에서 새로 생긴 것:

- **작업 일지.** "작업 영수증" 창이 **작업 기록** 창이 되었고, 오늘 / 7일 / 영수증 탭으로 나뉩니다. **오늘** 탭은 이 Mac의 Claude Code·Codex 세션 기록을 모아 프로젝트별로 작업 시간과 시간대, 에이전트에게 한 주요 요청, 바뀐 파일 수, 그 시간에 남긴 영수증을 보여 줍니다. 최근 7일을 넘겨 볼 수 있고, **복사**에서 스크럼 3줄이나 마크다운을 고릅니다.
- **커밋도 함께.** 따로 켜면 각 프로젝트의 git 기록을 읽기 전용으로 읽어 그날의 커밋과 미커밋 파일을 붙이고, 하위 폴더와 에이전트 워크트리를 원래 저장소로 묶습니다. 프로젝트가 데스크탑·문서 폴더에 있으면 macOS가 폴더 접근을 물어볼 수 있다고 먼저 알려 줍니다.
- **다시 로그인이 쉬워졌어요.** Claude Code 로그인이 풀리면 패널의 **브라우저에서 로그인** 한 번으로 끝납니다. 터미널 없이 브라우저가 열리고, 로그인을 마치면 UsageBar가 알아서 다시 확인합니다. 안 될 때는 **명령어 복사**로 터미널에서 할 수 있어요. 로그인이 풀린 동안에는 메뉴 막대에 오래된 숫자 대신 "!"가 보이고, 알림을 켰다면 한 번 알려 줍니다. 처음 연결 설정이 oh-my-zsh 같은 셸 시작 질문 때문에 실행되지 않던 문제도 고쳤습니다.
- **7일 탭.** 지난 버전의 최근 7일 요약 아래에 날짜별 작업 시간·프로젝트·커밋이 이어지고, 주간 마크다운으로 복사할 수 있습니다.

작업 일지는 기본으로 꺼져 있고, 처음 오늘 탭을 열 때 켤지 묻습니다. AI 요약 없이 이 Mac 안에서만 만들고 네트워크로 보내지 않습니다. 요청 문장은 저장하지 않고 화면에 그릴 때 원본 기록에서 첫 줄만 읽으며, 키·토큰·이메일처럼 보이는 값은 가립니다. 설정 → 작업 기록에서 요청 문장을 숨기거나 프로젝트를 빼거나 일지를 끌 수 있고, 끄면 캐시를 지웁니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

**English** — The receipts window is now the **Work Log** window with Today, 7 days and Receipts tabs. **Today** gathers this Mac's Claude Code and Codex session logs into a log by project: time worked and when, the main requests you gave the agents, changed files, and receipts recorded during that work. Step back through the last 7 days and copy a three-line stand-up or Markdown. Turn on commits separately to add the day's commits and uncommitted files and to group subfolders and agent worktrees under their repository; UsageBar first explains that macOS may ask for folder access. Signing Claude in again is one click: **Sign in with browser** runs Claude Code's own sign-in in your browser, no Terminal needed, and UsageBar checks again when you finish (or copy the command for Terminal). While signed out, the menu bar shows "!" instead of an old number, with a one-time notification if notifications are on. First-time Claude setup no longer breaks when a shell startup question, such as oh-my-zsh's update prompt, swallows the setup path. The 7-day tab keeps the weekly summary and adds each day's time, projects and commits, copyable as Markdown. The work log is off until you turn it on, is built on your Mac without AI and never leaves it, and never stores requests: their first line is read from the original log when drawn, with anything that looks like a key, token or email masked.
