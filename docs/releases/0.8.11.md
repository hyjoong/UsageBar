# UsageBar 0.8.11

- Codex 사용량 조회가 계속 "Codex 사용량을 읽지 못했어요"로 실패하던 문제를 고쳤습니다. PATH 앞쪽에 오래된 Codex CLI(예: nvm으로 전역 설치한 0.46)가 있으면, 그 버전이 버전 확인은 통과하지만 사용량 조회를 지원하지 않아 실패했습니다. 이제 실행 가능한 후보를 모두 비교해 가장 높은 버전을 사용합니다. 터미널에서 앱을 실행했을 때 특히 잘 드러났습니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — 0.8.11 fixes Codex usage failing with "couldn't read Codex usage" when an outdated Codex CLI (for example an old nvm global install) comes first on PATH. That version answers --version but cannot serve the usage methods. UsageBar now compares every runnable candidate and uses the newest one.
