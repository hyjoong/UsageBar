# UsageBar 0.8.6

영수증이 "얼마나 썼나"뿐 아니라 "무엇으로 어디서 썼나"까지 보여줍니다.

- **모델·토큰 상세.** 영수증에 작업 구간 동안 호출한 모델, 호출 수, 입력·출력·캐시 토큰, 프로젝트 폴더가 붙습니다. 패널 카드에는 한 줄 요약, 영수증 창에는 전체가 보이고, 요약 복사에도 포함됩니다.
- 출처는 Claude Code와 Codex가 이 Mac에 이미 남기는 세션 기록(`~/.claude`, `~/.codex`)입니다. 시각·모델명·토큰 수·폴더 이름만 집계하고 대화 내용은 저장하지 않습니다. 설정 → 작업 기록에서 끌 수 있습니다.
- 설정에 **작업 기록** 섹션을 만들어 세션 알림과 상세 수집 스위치를 모았습니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew install --cask hyjoong/tap/usagebar`.

---

**English** — 0.8.6 adds model and token details to receipts: which models were called, how many times, input/output/cache tokens, and the project folders, counted from the session logs Claude Code and Codex already keep on this Mac (`~/.claude`, `~/.codex`). Only timestamps, model names, token counts and folder names are read; conversation content is never stored. Toggle under Settings → Work log.
