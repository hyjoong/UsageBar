# UsageBar 0.8.8

- **리셋을 지난 세션도 영수증에 숫자가 남습니다.** 세션 중에 5시간 한도가 리셋되면 이전에는 "비교 불가"였지만, 이제 리셋 전 마지막 5분 조회값까지의 변화와 리셋 후 새 기간의 사용률을 합쳐 `≈+5%p`처럼 추정값으로 보여주고, 추정임과 내역(리셋 전 +3, 후 +2)을 함께 적습니다. 요약 복사에도 "약 +5%p (추정, 리셋 통과)"로 들어갑니다.
- 추정은 측정이 아니므로 ≈ 표시와 설명을 항상 붙입니다. 리셋 전 조회값이 없으면 이전처럼 사유만 표시합니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew install --cask hyjoong/tap/usagebar`.

---

**English** — 0.8.8 keeps a number on receipts for sessions that crossed a limit reset: the change up to the last 5-minute poll before the reset plus the new period's usage, shown as an estimate (≈) with its breakdown. Without a pre-reset poll the receipt still explains why no comparison was possible.
