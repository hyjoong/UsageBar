# UsageBar 0.8.15

- Claude 계정 정보를 잠깐 읽지 못했을 때 생기던 문제를 고쳤습니다. 예를 들어 Claude Code CLI가 스스로 업데이트하는 바로 그 순간이 그렇습니다. 지금까지는 이 한 번의 실패를 계정이 바뀐 것으로 보고 **Claude 조회 기록 전체를 지웠고**, 진행 중인 작업 영수증도 "같은 계정인지 확인할 수 없어요"로 끝났습니다.
- 이제 30분 안에 확인한 계정이 있으면 그 값을 이어 씁니다. 앱을 막 켜서 이전 값이 없을 때는 기록을 지우지 않고, 계정을 알 수 없는 그 한 번의 조회만 저장하지 않습니다. 실제로 다른 계정으로 바뀐 경우는 지금처럼 기록을 새로 시작합니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — 0.8.15 fixes a momentary failure to read Claude account metadata, for example while the Claude Code CLI updates itself, being treated as an account switch. That used to wipe the Claude history and leave a running session's receipt unable to confirm the account. A key seen in the last 30 minutes is now carried over. Right after launch, when there is none, the history is kept and only that one unattributable sample is skipped. A real account switch still starts a new history.
