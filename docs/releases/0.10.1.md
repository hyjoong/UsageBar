# UsageBar 0.10.1

0.10.0을 다듬고 버그를 고쳤습니다.

- **더 분명한 화면.** 패널 아래 "전체 기록"은 **기록 보기**가 되었습니다. "복사됨"은 2초 뒤 원래대로 돌아오고, 누를 수 없는 버튼(작업 시작·종료, 마지막 서비스 끄기)은 이유를 알려 줍니다. Codex 로그인 카드에도 **명령어 복사**가 생겼습니다.
- **키보드.** 작업 기록 창에서 ⌘[ ⌘]로 날짜를, ⌘1–3으로 탭을 바꿉니다. 사용 기록은 ⌘E로 CSV를 내보냅니다. Claude에는 일별 토큰이 없으므로 빈 탭을 숨겼습니다.
- **로그인 정리.** 브라우저 로그인을 기다리는 중에 UsageBar를 종료해도 로그인 프로세스가 남지 않습니다. 처음 실행처럼 로그인한 적이 없으면 "로그인이 풀렸어요" 알림을 보내지 않습니다.
- **작업 일지 정확도.** 자정 전에 시작해 자정을 넘긴 Codex 작업을 다음 날에도 셉니다. 홈 폴더의 dotfiles 저장소가 다른 폴더를 한 프로젝트로 묶지 않습니다. 교체된 로그는 한 번만 읽습니다. 작업 일지를 끄는 순간 진행 중이던 갱신이 캐시를 다시 쓰지 않습니다.
- **가리기 보강.** 접속 문자열의 비밀번호, `DB_PASSWORD=…` 같은 비밀값, `Bearer` 토큰을 가리고, 세션 제목·커밋 제목·PR 링크에도 같은 규칙을 적용합니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — Polish and fixes for 0.10.0. The panel's log button now reads **View log**; "Copied" resets after two seconds; disabled buttons say why; Codex sign-in gets **Copy command**. The work log window adds ⌘[ ⌘] for days and ⌘1–3 for tabs, and History adds ⌘E export and hides Claude's empty token tab. Quitting while a browser sign-in is waiting no longer leaves the sign-in process behind, and no "signed out" notice is sent before a first login. Codex turns that cross midnight count on the next day, a dotfiles repository in your home folder no longer groups other folders, replaced logs are read once, and turning the work log off cannot rewrite its cache. Masking now covers connection-string passwords, `NAME=value` secrets and Bearer tokens, and also applies to session titles, commit subjects and pull request links.
