# UsageBar 0.9.1

- **낮은 서비스만 주황색.** 메뉴 막대에 Claude와 Codex를 함께 표시할 때, 잔여율이 20% 이하인 서비스의 숫자만 주황색이 됩니다. 전에는 한쪽만 낮아도 라벨 전체가 주황색이어서 어느 쪽이 부족한지 알 수 없었습니다. 나머지는 메뉴 막대 글자색 그대로입니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — With both services in the menu bar, only the one at or below 20% turns orange; before, one low service turned the whole label orange, so it was unclear which one was low. Everything else keeps the menu bar's text color.
