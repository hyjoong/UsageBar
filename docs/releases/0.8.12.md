# UsageBar 0.8.12

- 메뉴 막대에서 U 아이콘을 빼고 **잔여율만** 표시합니다. 메뉴 막대 공간을 덜 차지하고, 노치에 가려질 가능성도 줄어듭니다.
- 0.8.10에서 추가한 **앱 아이콘 표시** 설정은 없앴습니다.
- 아직 확인한 한도가 없거나 잔여율 표시를 끄면 보여 줄 숫자가 없으므로, 그때만 U 아이콘이 나타나 메뉴 막대에서 앱을 열 수 있게 합니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — 0.8.12 drops the U icon from the menu bar and shows only the percentage, which takes less space and is less likely to hide under the notch. The Show app icon setting added in 0.8.10 is removed. The icon appears only while there is no percentage to show, such as before the first check or when the percentage is turned off, so there is always something to click.
