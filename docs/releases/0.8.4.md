# UsageBar 0.8.4

작업 기록을 켜 두고 잊는 일을 막습니다.

- **메뉴바 표시.** 기록 중에는 메뉴바에 ●와 경과 시간이 함께 보입니다.
- **알림으로 종료.** 시작 2시간 뒤 "아직 진행 중" 알림, 한도 리셋 10분 전 "지금 종료해야 비교 가능" 알림이 오고, 알림의 **작업 종료** 버튼으로 패널을 열지 않고 끝낼 수 있습니다. 설정 → 알림에서 끌 수 있습니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew install --cask hyjoong/tap/usagebar`.

---

**English** — 0.8.4 keeps a running work session from being forgotten: the menu bar shows a ● with the elapsed time, and notifications arrive 2 hours in and 10 minutes before the limit resets, each with a Finish button. Toggle under Settings → Notifications.
