# UsageBar 0.8.5

**핫픽스.** 0.8.4에서 작업 기록을 시작하면 메뉴바 라벨이 쉬지 않고 다시 그려져 CPU를 점유하고 앱이 멈춘 것처럼 보이는 문제를 고쳤습니다. 메뉴바의 경과 시간은 이제 앱의 1분 시계를 따릅니다.

0.8.4에서 앱이 멈춰 업데이트 확인이 안 되면, 앱을 강제 종료한 뒤 [Releases](https://github.com/hyjoong/UsageBar/releases/latest)의 ZIP으로 다시 설치하거나 `brew upgrade --cask usagebar`를 실행해 주세요. 설정과 기록은 유지됩니다.

---

**English** — Hotfix for 0.8.4: starting a work session made the menu bar label redraw endlessly and pin the CPU. If 0.8.4 is unresponsive, force quit and reinstall from Releases or run `brew upgrade --cask usagebar`.
