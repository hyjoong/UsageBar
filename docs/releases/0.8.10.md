# UsageBar 0.8.10

- 메뉴 막대에서 **앱 아이콘 없이 잔여율만** 표시할 수 있습니다. 설정 → 메뉴 막대 → **앱 아이콘 표시**를 끄면 됩니다. 아직 확인한 한도가 없거나 잔여율 표시를 끄면 아이콘이 다시 나타나 위치를 잃지 않습니다.
- 작업 기록 중에는 메뉴 막대에 경과 시간만 보이고 잔여율이 사라지던 문제를 고쳤습니다. 두 서비스를 함께 표시할 때 두 번째 잔여율과 서비스 기호가 빠지던 문제도 함께 고쳤습니다.
- Finder에서 실행한 앱이 Codex를 찾지 못하던 문제를 고쳤습니다. 설치된 후보를 차례로 확인해 실행되는 Codex를 고르고, 실패하면 **Codex 다시 연결** 카드로 안내합니다.
- 연결이 끊긴 동안 보이는 이전 기록은 큰 숫자 대신 "마지막 확인 시 N% 남음"으로 표시해 현재 값과 구분합니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew upgrade --cask usagebar`.

---

**English** — 0.8.10 adds an option to show only the percentage in the menu bar (Settings → Menu Bar → turn off **Show app icon**; the icon returns until a limit has been checked). The menu bar no longer drops the percentage while a session is recording, or the second service and its symbol when both are shown. Codex is found again when the app is launched from Finder, with a **Reconnect Codex** card when it still fails, and cached usage reads "N% left at last check" instead of a live-looking number.
