# UsageBar 0.8.9

- 패널 하단의 설정 아이콘(슬라이더)과 ⋯ 메뉴를 **톱니바퀴 메뉴 하나**로 합쳤습니다. 설정…, 창으로 열기, 공식 사용량 화면, 서비스 장애 현황, 종료가 한 메뉴에 있습니다. 하단은 새로고침 · 사용 기록 · 톱니바퀴 세 개입니다.
- Claude 연결을 고쳤습니다. 사용자 설치 경로(`~/.local/bin`, `~/.npm-global/bin`)의 Claude Code를 시스템 설치보다 먼저 찾고, 로그아웃 상태를 정확히 **로그인 확인 필요**로 표시합니다. 로그인이 만료되면 이전 기록 위에 연결 설정 열기·다시 확인 버튼이 있는 복구 카드가 나타나고, 구형 CLI에는 업데이트를 안내합니다.

macOS 14 이상·Apple Silicon. 설정 → 앱 정보 → 업데이트 확인으로 설치하거나 `brew install --cask hyjoong/tap/usagebar`.

---

**English** — 0.8.9 merges the sliders button and the ⋯ menu into one gear menu (Settings…, Open as Window, usage page, status page, Quit), leaving refresh, history and the gear in the footer. It also fixes Claude connection: user-installed Claude Code (`~/.local/bin`, `~/.npm-global/bin`) is found before system installs, a signed-out CLI is reported as "login needed" with a recovery card (open setup, check again) even when earlier usage is cached, and outdated CLIs get an update hint.
