# 지원 범위와 개인정보

| 서비스 | 표시하는 정보 | 제한 |
| --- | --- | --- |
| Claude | CLI `/usage`에 표시되는 세션·주간·모델 범위별 한도와 리셋 안내 | CLI 화면 형식에 의존합니다. 날짜를 해석하지 못하면 확인 가능한 원문 리셋 안내를 표시합니다. 일별 토큰 기록은 제공하지 않습니다. |
| Codex | App Server가 반환한 한도별 사용률·기간·리셋 시각, 저장된 초기화권 개수와 만료일, 일별 토큰 기록 | CLI 버전과 계정 응답에 따라 항목이 없을 수 있습니다. 초기화권 상세가 없어도 개수는 표시할 수 있습니다. |

미제공 값은 0으로 바꾸지 않습니다. **구독 종료일·다음 결제일·실제 청구액·프로젝트별 비용은 표시하지 않으며 초기화권을 소비하는 기능도 없습니다.** 사용 기록의 한도 변화는 앱이 실행되며 수집한 표본으로, Codex의 일별 토큰 기록과는 별개입니다.

Claude는 기존 로그인 상태로 CLI의 `/usage`를 실행합니다. Codex는 전용 자식 프로세스의 stdio 연결에서 `account/read`, `account/rateLimits/read`, `account/usage/read`를 읽습니다. 모델 작업을 요청하거나 OAuth 엔드포인트·Keychain을 직접 읽지 않습니다. 인증과 갱신은 각 CLI가 관리합니다.

표시용 메타데이터와 작업 기록은 이 Mac의 다음 파일에 저장합니다.

```text
~/Library/Application Support/UsageBar/usage-cache.json
~/Library/Application Support/UsageBar/work-journal.json
```

- 한도 변화 표본: 최근 30일, 전체 최대 60,000개·일별 최대 2,500개. 마지막 성공 조회 결과도 캐시합니다.
- 계정 구분: 해시된 식별자를 사용하며 계정 변경을 식별하면 이전 변화 기록을 분리합니다.
- 작업 기록: 진행 중인 체크포인트에는 계정 일치 확인용 해시만 보관하고 완료 영수증에서는 제거합니다.
- **원본 이메일·인증 토큰·대화 내용·프로젝트 파일·CLI 원문 응답은 저장하지 않습니다.** CSV에는 선택한 범위의 날짜·한도 이름·수치만 포함합니다.

## 영수증 상세(모델·토큰)의 출처

작업 영수증의 모델별 호출 수·토큰 수·프로젝트 폴더 이름은 Claude Code가 `~/.claude/projects/*/*.jsonl`에, Codex가 `~/.codex/sessions/**/*.jsonl`에 남기는 세션 기록에서 작업 구간(시작~종료)의 레코드만 집계한 값입니다. 각 줄에서 시각, 모델명, 토큰 수, 작업 폴더 경로의 마지막 요소만 사용하고 메시지 본문은 보관하지 않습니다. 집계 결과만 영수증에 저장되며, 설정 → 작업 기록 → "영수증에 모델·토큰 상세 포함"으로 끌 수 있습니다. 기록이 매우 크면 4초 안에 읽은 부분까지만 집계하고 그 사실을 영수증에 표시합니다.

## 작업 일지의 출처

작업 기록 창의 "오늘"·"7일" 탭에 보이는 일지는 설정 → 작업 기록 → "작업 일지 사용"을 켠 경우에만 만듭니다(기본 꺼짐). 입력은 이 Mac에 이미 있는 기록뿐입니다.

- Claude Code 세션 기록 `~/.claude/projects/*/*.jsonl`
- Codex 세션 기록 `~/.codex/sessions/**/*.jsonl`, `~/.codex/archived_sessions/*.jsonl`, 세션 제목 `~/.codex/session_index.jsonl`
- "git 커밋 포함"을 켠 경우에만 각 프로젝트의 git 기록(기본 꺼짐)
- 기존 작업 영수증

다음 원칙을 지킵니다.

1. **로컬 전용**: 일지 기능에는 네트워크 통신 코드가 없습니다. 원격 저장소(GitHub 등)도 조회하지 않습니다.
2. **요청 본문 미저장**: 캐시에는 요청(프롬프트) 본문을 넣지 않습니다. 요청은 `(파일, 바이트 위치, 길이, 시각)`만 저장하고, 화면이나 복사 텍스트를 만들 때 원본 세션 기록에서 그 줄을 다시 읽어 발췌합니다. 원본 기록을 지우면 일지에서도 사라집니다.
3. **최소 발췌**: 첫 줄만, 최대 80자까지 보여줍니다. 코드 블록으로 시작하는 붙여넣은 내용은 "(붙여넣은 내용)"으로 바꿉니다.
4. **비밀값 가리기**: API 키 모양의 값(`sk-…`, `ghp_…`, `github_pat_…`, `xox…`, `AKIA…`, JWT, 숫자와 글자가 섞인 32자 이상 덩어리), URL의 쿼리 문자열, 이메일 주소를 `•••`로 바꿉니다. 복사 텍스트에도 같은 규칙을 씁니다.
5. **선택권**: "요청 문장 표시"를 끄면 세션 제목만 보입니다. "제외할 프로젝트"에 적은 프로젝트는 일지와 복사 텍스트 모두에서 빠집니다. "작업 일지 사용"을 끄면 캐시를 지웁니다.
6. **저장 위치와 상한**: `~/Library/Application Support/UsageBar/worklog-index/` (폴더 0700, 파일 0600). 최근 8일치만 유지하고 전체 20MB를 넘기지 않으며, 경로에 심볼릭 링크가 있으면 쓰지 않습니다. 캐시에는 파일별 읽은 위치, 이벤트 시각, 작업 폴더 경로, 에이전트가 수정한 파일 경로, 세션 제목, PR 주소가 들어갑니다.
7. **git**: 읽기 전용 명령(`config user.email`, `log`, `status`)만 깨끗한 환경 변수로 실행합니다. 내 커밋만 고르기 위한 `user.email`은 실행할 때만 쓰고 저장하지 않습니다. 커밋 제목은 화면 표시용으로만 읽고, 원본 저장소에 이미 있는 정보입니다. 프로젝트가 데스크탑·문서 폴더에 있으면 macOS가 폴더 접근 권한을 물을 수 있으며, 거부하면 커밋 영역만 비고 나머지 일지는 그대로 보입니다. "git 커밋 포함"이 꺼져 있으면 프로젝트 폴더 안(`.git` 포함)을 읽지 않고 세션 기록의 작업 폴더 경로만으로 프로젝트를 묶습니다.
8. **AI 요약 없음**: 일지와 복사 텍스트는 규칙으로만 만들며, 어떤 내용도 모델에 보내지 않습니다.
